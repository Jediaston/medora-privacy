# Medora Privacy Policy

Public HTTPS privacy policy for **Medora** (`com.arkepi.medora`), published by **Arkë Pi**.

## Public URL (no login)

Preferred once GitHub Pages is enabled for this repo:

- https://jediaston.github.io/medora-privacy/

Available immediately (public repo, correct `text/html` MIME):

- https://raw.githack.com/Jediaston/medora-privacy/main/index.html

Source of truth in the app monorepo: `medora/play/privacy-policy.html` (and `privacy.html`) in [Jediaston/ai-build](https://github.com/Jediaston/ai-build).

This small public repo exists so Play Console can link a privacy URL without relying on the private `ai-build` GitHub Pages site.
